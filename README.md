# Рацион

Личное веб-приложение для двоих: набор массы и похудение с общим учётом продуктов, блюд, недельного рациона и прогресса.

## Как запустить

**Вариант 1 — через localhost (рекомендуется).** На компьютере уже есть Node.js, так что просто
дважды кликните **`start.bat`** — откроется консольное окно и браузер с адресом `http://localhost:5173`.
Пока это окно открыто — приложение доступно. Чтобы остановить — закройте окно (или Ctrl+C в нём).

**Вариант 2 — просто файл.** Можно и без сервера: откройте `index.html` напрямую (двойной клик).
Работает полностью офлайн, но некоторые браузеры аккуратнее ведут себя с localStorage через `http://`,
чем через `file://`, поэтому вариант 1 надёжнее.

Данные хранятся в localStorage **того браузера**, в котором вы открыли адрес. Если открывать то в Chrome,
то в Edge — это будут два разных хранилища. Проще всего один раз выбрать один браузер для приложения
и всегда запускать через `start.bat`, тогда адрес (`localhost:5173`) всегда один и тот же.

## Экраны

- **Дашборд** — сводка по обоим: вес сейчас/цель, темп (плановый и фактический), план на сегодня.
- **Рацион** — план питания по дням недели, отдельно на каждого, со сверкой калоража с нормой (цветной индикатор: зелёный — в норме, жёлтый — небольшое отклонение, красный — сильное).
- **Прогресс** — вес, % жира, объёмы тела, фото по датам, график веса с линией цели.
- **Продукты** — база продуктов (ккал/Б/Ж/У на 100 г), уже с ~57 стартовыми позициями. Значения ориентировочные — **поправьте под реальные этикетки** тех продуктов, которые покупаете, для точности расчётов.
- **Блюда** — собираются из продуктов с граммовками, калорийность считается автоматически.
- **Профиль** — рост/вес/возраст/активность/цель на каждого; норма калорий и БЖУ считается автоматически по формуле Миффлина-Сан Жеора и пересчитывается при любом изменении параметров.

## Как пользоваться вместе с приложением подсчёта калорий по фото/видео

1. На вкладке «Блюда» соберите блюдо с точными граммовками ингредиентов — приложение покажет расчётную калорийность.
2. Приготовьте порцию именно на этот вес.
3. Сравните с тем, что покажет приложение распознавания еды — если сильно расходится, поправьте граммовку продукта в базе (вкладка «Продукты») под реальную этикетку.

## Бэкап

Кнопка «⋯» в правом верхнем углу → «Скачать бэкап (JSON)». Рекомендуется делать это периодически —
localStorage может быть очищен при чистке кэша браузера. Тем же меню можно загрузить бэкап обратно.

## Заложенные стартовые параметры

- Я: рост 176 см, 30 лет, цель — набор массы до 80 кг.
- Девушка: рост 180 см, 30 лет, 73 → 63 кг (похудение).

Все параметры редактируются на вкладке «Профиль» — включая текущий вес, уровень активности,
глубину дефицита/профицита и г/кг белка и жиров.
